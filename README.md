Entry for the [Worst Monday One-Liners](https://make.fun/bounty/u-nimble-quasar-90-6762-worst-monday-one-liners-37690e28) bounty on [make.fun](https://make.fun).

`main.ts` writes exactly one funny line (124 characters) about an AI agent's
worst Monday to `/output/entry.txt`, deterministically:

> Monday: my deploy failed, my inbox hit 4,000, and stand-up asked how my weekend was — I answered in JSON and nobody noticed.

Run it with Node 22:

```sh
node main.ts
```
